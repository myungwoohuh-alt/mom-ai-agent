# 엄마와 함께 AI 동굴 탐사

엄마와 아이가 함께 '미래로 통하는 동굴'을 탐사하며 Python,코딩 구조,'LLM'연결, 작은 'AI agent 만들기'를 직접 경험해보는 프로젝트입니다.
동굴은 '디지털화된 세계'를 의미하고, 동굴탐사는 '현실의 삶'에서 미래 적응을 위한 기본개념을 자연스럽게 습득하는 과정을 보여줍니다.
컴퓨팅도 제대로 모르던 분이 직접 2달 동안 'ChatGPT'와 협업했던 생생한 체험을 바탕으로 만들어진 살아있는 프로그램 입니다.  

## 준비물
-Windows 컴퓨터
-Python
-VS Code
-스마트폰 

## 프로젝트 받기
GitHub에서 프로젝트 페이지에서 Code 버튼을 누릅니다.
연속 5 단계로 각각 독립적 파일로 구성되어 있습니다.
Download ZIP을 선택해 파일을 내려 받습니다.
다운로드한 ZIP 파일 압축을 풀고 mom-ai-agent 폴더를 엽니다.

## 실행 순서
1. cave.py
2. cave_two_paths.py
3. cave_water_path.py
4. cave_agent.py
5. cave_journey.py

## 실행 방법
VS Code에서 Terminal을 열고 아래 명령어를 순서대로 실행합니다.
python cave.py
python cave_two_paths.py
python cave_water_path.py
python cave_agent.py
python cave_journey.py

## AI 연결 준비
'LLM'을 위한 'app.py 파일'을 실행하려면 OpenAI API 연결이 필요합니다.

### 필요한 패키지 설치 
'app.py'의 Terminal에서 아래 명령어를 실행합니다.
pip install openai
pip install pillow openai Python-dotenv

### API 키 설정 및 안전 보관
프로젝트 폴더에 '.env 파일'을 만들고 아래 형식으로 입력합니다.
OPENAI_API_KEY=(자신의_API_키 복사)

※ 실제 API 키는 다른 사람에게 보여주거나 GitHib에 올리지 마세요.

### API 요금 주의
OpenAI API 사용에는 별도의 요금이 발생할 수 있습니다.
실습과정이라 최소금액으로 하는 것을 추천 합니다,
결제 설정 시 자동 충전(Auto-reload)이 켜져있으면 반드시 확인하세요.
계속 자동 결제되는 것을 원하지 않으면 Auto-reload를 꺼주세요.

### AI 실행
API 키 설정이 끝나면 Terminal에서 아래 명령어를 실행합니다.
python app.py

## 코딩 실습
코딩을 어떻게 하는건지 그 표현 구조를 느끼도록 보여주는 과정입니다.
특히 if,elif,else의 선택 구조를 강조합니다. 
보여주는 코딩을 똑같이 그대로 입력하고 실행까지 직접 해봅니다.
'들여쓰기', 기호나 점하나 까지 검토하고 저장한 뒤 실행하도록 반복합니다.
특히 대문자나 소문자의 오타에 예민한 만큼 재확인 강조합니다. 

## 동굴탐사 과정 기록
가능한 많이 새로운 것, 알게 된 것, 느끼는 것, 미래에 하고 싶은 것들을 간략하게 요약해 기록합니다.
(아이)와 (엄마)는 서로 다르게 느낄 수밖에 없는 자신의 기록을 각각 수시로 기록합니다.
'trip.txt'라는 별도 파일 만들어 앞에 (아이)(엄마)를 먼저 쓰고 함께 사용합니다.

## 자신만의 'AI agent' 만들기
동굴탐사 과정 중 기록했던 내용들을 직접 읽고, 지시하는 목표에 맞게 분류 정리 부탁합니다.
이렇게 정리된 결과를 (아이)(엄마) 각각의 새파일을 만들어 저장합니다.
아주 작지만 'AI agent'를 직접 코딩해 만들어 실행까지하는 경험을 합니다.
각각 자신들의 새파일에 에이전트가 분류 저장해준 내용들을 보면서 지난 탐사과정을 되돌아 봅니다.
